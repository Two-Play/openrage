Getting started

Install OpenRAGE, point it at your game and let it take the archive keys from your own copy.

On this page
  1. Download a release
  2. Build from source
  3. Set up GTA V
  4. Set up Red Dead Redemption 2
  5. Next steps

1. Download a release

Ready-made builds for Linux (x86-64, glibc 2.35 or newer) and Windows (x86-64) are on the releases page. Unpack the archive and run openrage-gui, or openrage for the command line. SHA256SUMS.txt lists the checksums of the archives.

Linux (.tar.gz) Windows (.zip)

To check a download on Linux:

sha256sum --check --ignore-missing SHA256SUMS.txt

2. Build from source

You need a recent stable Rust toolchain; the exact version is pinned in rust-toolchain.toml and rustup picks it up automatically. On Linux the GUI also needs the development packages of fontconfig, xkbcommon, Wayland and ALSA: 

# Fedora
sudo dnf install fontconfig-devel libxkbcommon-devel wayland-devel alsa-lib-devel
# Debian / Ubuntu
sudo apt install libfontconfig1-dev libxkbcommon-dev libwayland-dev libasound2-dev

Then clone and build:

git clone https://github.com/Two-Play/openrage.git
cd openrage
cargo build --release
# binaries: target/release/openrage (CLI) and target/release/openrage-gui

For a reproducible environment there is a container image based on Fedora's toolbx image (dev/Containerfile); see Reproducible build environment in the README.

3. Set up GTA V

OpenRAGE needs the archive keys from your own game installation. On first start the GUI shows a setup dialog that detects Steam installations and derives the keys. On the command line: 

openrage --game "/path/to/Grand Theft Auto V" keys

The keys are extracted once and cached at ~/.config/openrage/gtav.keys (Linux) or %APPDATA%\openrage\gtav.keys (Windows). The game directory is remembered after this step.

  • GTA V Legacy (GTA5.exe): all keys are found in the executable.
  • GTA V Enhanced (GTA5_Enhanced.exe): the executable only contains the AES key; the NG keys are no longer stored in plain form. Pass a CodeWalker key blob you obtained yourself: openrage keys --magic /path/to/magic.dat. The blob is decrypted with the AES key from your executable and verified against common.rpf before it is cached.

Never share the key cache. It contains keys taken from your copy of the game.

4. Set up Red Dead Redemption 2

Reading RDR2 archives works on the command line. Unlike GTA V's, most RDR2 archive keys are not stored in the executable on disk; they exist only while the game runs. OpenRAGE takes them from your own game and never ships them. There are two ways:

From a key file

openrage rdr2-keys --file secrets.bin "/path/to/Red Dead Redemption 2"

The file holds length-prefixed key blocks, such as the secrets.bin Swage writes.

From a memory dump of your running game

  1. Start RDR2 in story mode (not Red Dead Online) and wait for the main menu, or load a save.
  2. Dump the process. On Windows: Task Manager → Details → right-click RDR2.exe → Create dump file. Under Proton/Linux: gcore <pid of RDR2.exe> (from gdb).
  3. Run openrage rdr2-keys --dump <dump file> "/path/to/Red Dead Redemption 2".

Delete the dump afterwards. It is several gigabytes and holds everything the game had in memory, including login data.

The keys are stored in OpenRAGE's config folder (rdr2.keys). Then list or read the archives: 

openrage rpf8 "/path/to/Red Dead Redemption 2"
openrage rpf8 --list "/path/to/Red Dead Redemption 2/common_0.rpf"

Only the Steam version of 2 April 2024 is known so far; other versions report which pieces are missing. Browsing RDR2 in the GUI and its file formats follow.

5. Next steps

Start the explorer, or try a few commands. Paths are virtual: archives, including archives inside archives, behave like folders.

openrage-gui
openrage ls x64a.rpf/data
openrage find adder.yft
openrage search 0xB779A091                     # hash lookup
openrage extract common.rpf/data/cargens.meta -o out/
openrage model …/adder.yft --export adder.glb  # glTF for Blender

Edits never touch your game files: they go to OpenIV's mods folder and can be undone. The README documents every part of the GUI and the complete command line. Found a bug or missing a format? Open an issue.
