# RPF9 candidate names

`rpf9-names.txt` combines the existing local candidate dictionary with the
64-bit matches from the completed 30-minute GPU extension pass. All distinct
candidates from that pass were recomputed on CPU and checked against the
exported RPF9 name-hash targets before inclusion. No 32-bit-only GPU results
were added. Counts are recorded in `rpf9-names-provenance.json`.

To use it, copy the file beside `game_scarlett_master.exe`, or set `RPF9_NAMES`
to its absolute path before starting OpenRAGE. The existing TOC reader loads
this sidecar; a rebuild is not required when updating the game-side copy.

A matching hash identifies a candidate path or stem, not necessarily the
original spelling or extension. Multiple candidates are preserved rather than
silently choosing one. A global match in both hash sets is not proof that both
hashes belong to the same archive entry. The application retains its existing
ambiguity handling and hash fallback.

The expanded pass tested 832,157,301 candidates using bounded numeric
neighbours, suffixes, observed directories and RAGE extensions. It read
dictionary files and exported hash lists, not game archive payloads. It found
26,821 additional distinct 64-bit hashes covering 26,880 additional entries
relative to the earlier GPU and CPU extension results. Those delta counts
describe the exported corpus, not unique lines in this dictionary.

Sources include the local installed-game TOC inventory, existing RDR2/GTA V
candidate lists, local executable strings, and
[GTA6-StringsDatabase](https://github.com/ahmed605/GTA6-StringsDatabase), pinned
to `2ec950606516e5e734230ab9bd74d42e88770627`. The latter's MIT notice is
preserved in `GTA6-StringsDatabase-LICENSE.txt`. Names generated by mutation
are hypotheses checked against the exported hashes, not files recovered from
that repository. This directory contains no decryption keys or asset payloads.
